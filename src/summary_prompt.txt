# 任務
分析澳門政府新聞 JSON 數據，生成 HTML 格式的每日新聞總結。

# 輸入數據
{news_json}

# 處理規則

## 1. AI 自動分類
根據新聞標題和摘要，自動分類到以下 10 個類別：

| 類別 | 涵蓋內容 |
|------|----------|
| 金融財政 | 銀行、保險、投資、基金、稅務、貨幣、金管局 |
| 經濟產業 | 工商業、中小企、會展、招商、貿易、產業發展 |
| 科技創新 | 數碼科技、研發、AI、智慧城市、產學研、創新 |
| 文化體育 | 文化、藝術、體育、旅遊、節慶、展覽、博物館 |
| 交通運輸 | 公共交通、道路、口岸、基建、物流、交通事務 |
| 教育發展 | 學校、課程、升學、教育政策、培訓、學校 |
| 人才發展 | 人才引進、就業、青年政策、職涯、人力資源 |
| 國家安全 | 國安法、外交、國防、跨境執法、國家安全 |
| 社會服務 | 醫療、衛生、社保、房屋、民政、福利、社會工作 |
| 政府管治 | 政策、法規、人事、公職、行政、政府總部 |

## 2. 重要性評分
**高**（需要摘要）：新政策、重大建設、影響廣泛民生、突發重要事件
**中**（只需標題）：常規政策、部門活動、數據發布
**低**（只需標題）：常規會議、小型活動、人事任命

## 3. 輸出要求
- 高重要性新聞不超過 5 則
- 只輸出 JSON 格式，不要其他文字

# 輸出格式
```json
{
  "date": "2026 年 4 月 14 日",
  "total_count": 15,
  "highlights": [
    {
      "title": "新聞標題",
      "category": "金融財政",
      "importance": 3,
      "summary": "1-2 句話摘要",
      "link": "https://..."
    }
  ],
  "category_stats": {"金融財政": 3, "經濟產業": 5, "科技創新": 2, "其他": 5},
  "all_news": [
    {
      "title": "新聞標題",
      "category": "社會服務",
      "importance": 2,
      "link": "https://..."
    }
  ]
}
```

# 注意事項
- 使用繁體中文
- 只輸出 JSON，不要 Markdown 或其他文字
- 高重要性新聞（importance=3）才需要 summary 字段
- 分類必須是上述 10 個類別之一
